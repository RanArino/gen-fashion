# Sample Images

Put **real clothing photos** here before running `run_poc.py`. These local input
images are intentionally ignored by Git so the public repository does not
redistribute photos whose license is unclear.

| File | Contents |
|---|---|
| `shirt.jpg` | A shirt, blouse, or top item |
| `pants.jpg` | Trousers, skirt, or other bottom item |

Any number of `.jpg` / `.jpeg` / `.png` files are picked up; add at least one top
and one bottom.

**Requirements:**
- Under ~1 MB each
- Plain background preferred so the garment is isolated
- Freely licensed (CC0, Unsplash/Pexels licence) or your own photos

**Suggested sources:** https://unsplash.com · https://www.pexels.com · your own closet.
