# サービス要件定義書（Phase 00：全体構想）

## 1. サービス概要
本サービスは、個人の所有する衣服をデジタル化（デジタルワードローブ）し、AIと人間のプロデザイナーの感性を融合させることで、日々のスタイリング決定を自動化・最適化する次世代ファッションSaaSプラットフォームである。

単なる管理ツールにとどまらず、気象データ連動、洗濯ケア提案、実店舗での購買意思決定支援（OMO）、そしてクリエイターエコノミーを統合した、ファッション・ライフスタイル・オペレーティングシステムを目指す。

## 2. ターゲットユーザー
- 毎朝の服装選びに時間を費やしている（決定疲れを感じている）ビジネスパーソン・学生
- 自分の持っている服を把握しきれず、似たような服を買ってしまう傾向がある人
- サステナビリティに関心があり、手持ちの服を長く、効率的に活用したい人
- プロのデザイナーやスタイリストの感性を取り入れたいファッション関心層

## 3. 機能要件（コア機能）

### 3.1 デジタルクローゼット構築とAI自動タグ付け
- **衣服のデジタル化**: スマートフォンカメラで衣服を撮影し、背景を自動除去して保存。
- **ベクトル化と生成AI解析**: 画像からシルエット、素材感、色、デザイン特徴を抽出し、多次元ベクトルとして保存。
- **自動タグ付け**: カテゴリ（シャツ、パンツ等）、カラー、季節感、素材、ケア方法（洗濯タグOCR）をAIが自動認識。

### 3.2 ダイナミック・スタイリング・エンジン
- **週間プランニング**: 向こう1週間分のコーディネートをクローゼット内のアイテムから一括提案。
- **気象・コンテキスト連動**: 気温、降水確率に加え、湿度や体感温度に基づき、素材の通気性なども考慮して提案を動的に調整。
- **イベント・シーン別提案**: 「オフィスカジュアル」「週末のランチ」「結婚式二次会」などの予定に合わせたスタイリング生成。

### 3.3 アセット管理とアパレルケア
- **使用率（CPW）の可視化**: 着用回数と購入価格から「1回あたりのコスト」を算出し、衣服の活用状況を可視化。
- **洗濯・メンテナンス提案**: 洗濯タグのOCR解析に基づき、適切な洗濯方法、アイロン温度、クリーニングのタイミングをプロアクティブに通知。

### 3.4 OMO（Online Merges with Offline）購買支援
- **実店舗クロスドメインマッチング**: 店舗で気になる服をスキャンし、自宅のクローゼットアイテムとの相性をその場でシミュレーション。
- **ハイインテントデータの活用**: 「店舗で撮影したが購入しなかった服」を「興味関心オブジェクト」として記録し、後日のレコメンド（セール通知や類似安価アイテムの提案）に活用。

### 3.5 デザイナー参画型学習ループ（Human-in-the-Loop）
- **デザイナー・テンプレート**: 有志のプロデザイナーやスタイリストが、色合わせやレイヤードのロジックを提供。
- **協調学習**: デザイナーの感性を教師データとしてAIが学習し、画一的ではない「センスの良い」提案へと継続的に洗練。

## 4. 収益モデル（マネタイズ）
1. **文脈型アフィリエイト**: 提案されたスタイリングに足りないピース（靴、アクセサリー等）をECサイトから提案し、購入時に成果報酬を獲得。
2. **クリエイターエコノミー**: デザイナーのスタイリングが利用された際のインセンティブ付与、またはアフィリエイト報酬のレベニューシェア。
3. **B2B送客・購買支援手数料**: 提携ブランドのアイテムがアプリ経由で購入された際、または店舗での意思決定を支援した際の送客手数料（10%程度）。
4. **広告モデル**: スタイリング内に自然な形でスポンサーアイテムを組み込むネイティブ広告。

## 5. 非機能要件
- **画像処理パフォーマンス**: 撮影から背景除去・タグ付け完了まで数秒以内（UXの摩擦ゼロ化）。
- **検索精度**: ベクトル検索による高度な類似アイテムマッチング。
- **スケーラビリティ**: 数百万規模のユーザーの画像データとベクトルインデックスを効率的に管理。
